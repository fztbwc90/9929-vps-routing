## 9929 是什么线路？和联通 169、CN2 GIA 什么关系

一句话：9929 是联通的优化骨干网（老网通 CNCNET，俗称联通 A 网），主要承载企业宽带和 IDC 专线，很少分配给家宽，所以晚高峰的拥塞程度远低于普通线路。

联通一共三条干线，商家口中的“联通精品线路”"CU Premium""CUII"都绕不开它们：

- **AS4837（CHINA169，联通 169 网）**：普通家宽在用的线路，商家页面写“联通直连”的基本就是它；
- **AS9929（CNCNET，联通 A 网）**：优化线路，企业专线出身，本文的主角；
- **AS10099（中国联通国际）**：负责国际段接入，9929 出入境时都会经过它。

一台标准的联通精品线路 VPS，完整路由形态是 AS4837 → AS9929 → AS10099。至于和电信 CN2 GIA 的对比，商家宣传口径是“堪比 CN2 GIA"，实际两者档次接近：你是联通宽带，走 9929 最顺；电信宽带对应 CN2 GIA；移动那边对应的是 CMIN2。

## 判断真 9929：别看宣传图，跑一次回程路由

"9929 优化"是个容易被模糊的词。有的商家只做回程 9929（去程走电信 cogent 或其他线路），有的做双向 9929。单程和双向当然有差别，但对日常体验影响最大的是回程——数据从 VPS 回到你家那一段，才是晚高峰最挤的方向。

验证方法很直接：用 NextTrace 或 BestTrace 对电信、联通、移动三网节点各跑一次 traceroute，认两个标志：

1. 路径里出现 **AS9929 [CNC-BACKBONE]** 的节点，描述带 "CUII" 字样；
2. 国际段先经过 AS10099 [CUG-BACKBONE] 再转进 9929，属于正常形态。
